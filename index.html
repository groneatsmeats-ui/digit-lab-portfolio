What am I changing?

Neurons & hidden layers

Neurons combine input numbers. More neurons give the network more capacity to learn patterns. Extra layers combine those patterns—but bigger is not always better.

Activation functions

ReLU: keeps positive values and turns negative values into zero. A useful starting point.
Sigmoid: squeezes values between 0 and 1.
Tanh: squeezes values between −1 and 1.
These functions help a network learn more than straight-line relationships.

What does accuracy mean?

The percentage of 10,000 validation digits the network labels correctly. Those digits are not used to update its weights. The separate official test set is saved for final judging.
